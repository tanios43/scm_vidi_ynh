# SCM Vidi

Application de gestion pour une SCM d'orthoptie — planning et charges partagés entre associés.

## Fonctionnalités

- **Charges** : répartition des charges fixes/variables entre associés (Yssingeaux / Le Puy)
- **Planning** : gestion des créneaux par cabinet et par praticien, jours fériés, templates
- **Données partagées** : backend Flask + SQLite, toute l'équipe voit les mêmes données
- **Rôles** : un admin peut modifier, les autres consultent

## Accès

Réservé aux utilisateurs YunoHost. L'utilisateur admin choisi à l'installation peut modifier les données.
